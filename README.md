## Description

Botbreeze is a lightweight bot built in just a few lines of code! It Has an estimated elo of 1800.
You can now play it in [Lichess.](https://lichess.org)

*BotBreeze is still in version 1.0.0-alpha. Expect improvements and changes*
### Features:
- Negamax with prunning
- Quiescence search
- PSTs
- TT
- Iterative deepening with aspiration windows 
- ... And many more!

## Instalation:
### Prerequisites:
Before you begin, ensure you have installed the following:
- Python 3.8 or higher
- Pip(Python package installer)
- Git

The installation is really simple:

Clone the repository:
```bash
git clone https://github.com/Playdev05/BotBreeze.git
cd BotBreeze
```

Install dependencies:
```bash
pip install -r requirements.txt
```

Run the application:
```
python run_engine.py
```
